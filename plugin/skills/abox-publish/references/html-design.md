# HTML 기본 디자인 지침

환경에 디자인 스킬이 없을 때 HTML 아티팩트에 쓰는 최소 기준이다. 결과물 규칙(파일·경로·외부 주소·런타임 기능)은 SKILL.md의 'HTML'을 따른다.

## 구성

- 맨 위에 제목과, 무엇을 다루고 결론이 무엇인지 한두 문장을 둔다. 장식용 히어로 섹션은 만들지 않는다.
- 중요한 것부터 놓는다. 숫자 비교는 표나 차트로, 단계는 번호 목록으로 보여 준다.
- 탭·접기 같은 상호작용이 없어도 처음 화면에서 핵심 내용이 보이게 한다.

## 색

- `:root`에 색 토큰(배경·표면·글자·보조 글자·선·강조)을 두고, 화면의 색은 모두 토큰으로 쓴다.
- `@media (prefers-color-scheme: dark)`에서 같은 토큰을 다시 정의하고, `body`에 배경색을 직접 정한다.
- 강조색은 하나만 쓰고, 상태색(성공·경고·위험)은 의미가 있을 때만 쓴다.

## 글자와 폭

- 글꼴은 시스템 글꼴 스택을 쓴다: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif`.
- 본문은 16px, 줄 간격 1.6~1.75, 한글은 `word-break: keep-all`.
- 본문 폭은 `max-width: 46rem` 안팎으로 두고, 표·차트만 넓게 쓴다.
- 제목 단계는 세 개까지 쓴다.
- 390px 폭에서 가로 스크롤이 없어야 하고 좌우 여백은 16px 이상이다. 넓은 표는 자체 `overflow-x: auto`로 감싼다.

## 차트

- 라이브러리는 정확한 버전의 CDN 주소로 불러온다(`https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js`).
- 차트 색은 색 토큰에서 가져와 다크 모드에서도 읽히게 한다.
- 축 이름·단위·범례를 단다. 수치가 몇 개뿐이면 차트보다 표나 큰 숫자가 낫다.

## 피할 것

- 카드 안에 카드를 넣거나, 모든 내용을 카드로 나누기
- 장식용 그라디언트·흐린 원·글로우, 이모지 아이콘
- 화면 전체를 한 색 계열로만 채우기
- 의미 없는 애니메이션
